# 4.4 资源管理与对象池 — 关键代码与说明

本节覆盖 **`SafeObjectPool<T>`**（空闲队列 + 工厂 + 可选重置）、**`GameObjectPool`**（预制体实例、父节点、**`IReusable`** 钩子）、**`ResourceLoader`**（编辑器 `Resources` / 发行版 `Addressables`）、以及 **`ResourcePoolManager`** 对多池的注册与按 key 取用。**目标**：把「获取 → 使用 → 回收」固化在少数类型里，摊平实例化尖峰、便于统一加载策略。

## 4.4.2 底层队列池（`SafeObjectPool<T>`）

```csharp
public T get()
{
    lock (_lock)
    {
        if (_idleObjects.Count > 0) return _idleObjects.Dequeue();
    }
    return _createFunc();
}

public void Release(T obj)
{
    if (obj == null) throw new ArgumentException(nameof(obj));
    _resetAction?.Invoke(obj);
    lock (_lock)
    {
        if (_idleObjects.Count < _maxCapacity)
            _idleObjects.Enqueue(obj);
    }
}
```

空闲数超过 **`_maxCapacity`** 时 `Release` 不再入队，对象交给 GC。**`PreloadInitial`** / **`Clear`** 等见完整类型定义。

## 4.4.3 加载器（`ResourceLoader`）

```csharp
public T LoadSync<T>(string resourcePath) where T : UnityEngine.Object
{
#if UNITY_EDITOR
    return Resources.Load<T>(resourcePath);
#else
    var handle = Addressables.LoadAssetAsync<T>(resourcePath);
    handle.WaitForCompletion();
    return handle.Result;
#endif
}

public void Unload<T>(T resource) where T : UnityEngine.Object
{
#if UNITY_EDITOR
    Resources.UnloadAsset(resource);
#else
    Addressables.Release(resource);
#endif
}
```

`LoadAsync` 在编辑器走 `Resources.LoadAsync`，在发行版走 `Addressables` 并完成回调。

## 4.4.4 `GameObjectPool`：构造、取出、归还

```csharp
public GameObjectPool(GameObject prefab, Transform poolParent = null, int initialCapacity = 0, int maxCapacity = 100)
{
    _poolParent = poolParent ?? new GameObject("GameObjectPool").transform;
    _poolParent.gameObject.SetActive(false);

    Func<GameObject> createFunc = () => {
        var obj = GameObject.Instantiate(prefab, _poolParent);
        obj.name = prefab.name;
        obj.SetActive(false);
        return obj;
    };

    Action<GameObject> resetAction = (obj) => {
        obj.transform.SetParent(_poolParent);
        obj.SetActive(false);
        obj.transform.localPosition = Vector3.zero;
        obj.transform.localRotation = Quaternion.identity;
        obj.transform.localScale = Vector3.one;
        if (obj.TryGetComponent(out IReusable reusable)) reusable.OnDespawn();
    };

    _internalPool = new SafeObjectPool<GameObject>(createFunc, resetAction, initialCapacity, maxCapacity);
}

public GameObject Spawn(Vector3 position, Quaternion rotation, Transform parent = null)
{
    lock (_lock)
    {
        GameObject obj = _internalPool.get();
        obj.transform.SetParent(parent, false);
        obj.transform.position = position;
        obj.transform.rotation = rotation;
        obj.SetActive(true);
        _usedCount++;
        if (obj.TryGetComponent(out IReusable reusable)) reusable.OnSpawn();
        return obj;
    }
}
```

`Despawn` 调用 `_internalPool.Release`（内部会先经 `resetAction`，含 `OnDespawn`）。

## 4.4.5 `GenericResourcePool<T>` 与 `GameObjectPool` 的差异（概念）

- **`GameObjectPool`**：每次 **`Spawn`** 后对挂载的 **`IReusable`** 调 **`OnSpawn`**；**`resetAction`** 里调 **`OnDespawn`**。
- **`GenericResourcePool<T>`**：在内层 **`createFunc` 包装里可对新建实例调一次 `IReusable.OnSpawn`**；从空闲队列复用时依赖额外的 **`onSpawn` 委托** 做「取出后初始化」，否则需保证工厂与委托语义一致。

---

## 4.4.6 `ResourcePoolManager`（概念）

单例维护 **`Dictionary<string, IResourcePool<GameObject>>`** 与装箱的泛型池；**`CreateGameObjectPool`** / **`CreateGameObjectPoolFromResource`**（经 **`IResourceLoader.LoadSync<GameObject>`**）注册；**`SpawnGameObject` / `DespawnGameObject`** 按 pool key 转发。**`ClearAllPools`** 清空各池空闲队列。

---

## 4.4.7 使用示例

```csharp
ResourcePoolManager.Instance.Initialize(); // 可注入自定义 IResourceLoader
var pool = ResourcePoolManager.Instance.CreateGameObjectPool("Vfx", prefab, 10, 100);
var go = ResourcePoolManager.Instance.SpawnGameObject("Vfx", pos, rot, parent);
ResourcePoolManager.Instance.DespawnGameObject("Vfx", go);
```
