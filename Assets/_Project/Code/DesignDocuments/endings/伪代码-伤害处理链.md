# 5.4.2 伤害处理链 — 关键代码与说明

玩法侧把一次「来源对目标的可结算作用」建成 **Impact 事件实体**（`ImpactEventComponent` + `ImpactValueComponent`），由 **`ImpactManager.CreateImpactEvent`** 创建，**`ImpactSystem`**（`UpdateOrder = 31`）在 ECS 更新中消费：命中检查 → 暴击 → 目标修饰器与防类型合成 → 写回 **`EntityDataComponent`**，并更新承伤黑板、触发受击表现。**`UnitVitalitySystem`**（`UpdateOrder = 32`）等在更晚顺序处理生死门槛与播报，避免把整条链路塞进 Impact。

枚举 `ImpactType`、`ImpactSourceType`、`ImpactOperationType`、`TargetAttribute` 等见 `Gameplay/Impact/ImpactEnums.cs` 与 `ImpactEventComponent`、`ImpactValueComponent`、`ImpactModifierComponent` 定义。

## 5.4.2.1 创建事件（`ImpactManager`）

```csharp
public EcsEntity CreateImpactEvent(
    EcsEntity source,
    EcsEntity target,
    TargetAttribute targetAttribute,
    float value,
    ImpactOperationType operationType = ImpactOperationType.Add,
    ImpactType impactType = ImpactType.Physical,
    ImpactSourceType sourceType = ImpactSourceType.NormalAtk)
{
    var eventEntity = _world.CreateEntity();
    var eventComponent = new ImpactEventComponent();
    eventComponent.InitializeDefaults();
    eventComponent.Source = source;
    eventComponent.Target = target;
    eventComponent.TargetAttribute = targetAttribute;
    eventComponent.OperationType = operationType;
    eventComponent.ImpactType = impactType;
    eventComponent.SourceType = sourceType;
    eventEntity.AddComponent(eventComponent);

    var valueComponent = new ImpactValueComponent();
    valueComponent.InitializeDefaults();
    valueComponent.BaseValue = value;
    valueComponent.Type = impactType;
    eventEntity.AddComponent(valueComponent);
    return eventEntity;
}
```

`AddModifier` / `RemoveModifier` / `ClearModifiers` 维护目标上的 **`ImpactModifierComponent.Modifiers`**。

普攻投递示例：`EcsWorld.Instance.CombatImpacts.CreateImpactEvent(攻方, 守方, TargetAttribute.Hp, rawAtk, ImpactOperationType.Subtract, ImpactType.Physical, ImpactSourceType.NormalAtk)`。

## 5.4.2.2 消费主循环（`ImpactSystem.Update` 节选）

```csharp
public int UpdateOrder => 31;

private void Update(float deltaTime, EcsWorld world)
{
    var eventEntities = world.GetEntitiesWithComponent<ImpactEventComponent>().ToList();
    foreach (var eventEntity in eventEntities)
    {
        var impactEvent = eventEntity.GetComponent<ImpactEventComponent>();
        if (impactEvent.IsProcessed || _processedEvents.Contains(impactEvent.EventId)) continue;

        if (!impactEvent.Source.IsValid() || !impactEvent.Target.IsValid()
            || !impactEvent.Target.HasComponent<EntityDataComponent>())
        {
            impactEvent.IsProcessed = true;
            eventEntity.SetComponent(impactEvent);
            _processedEvents.Add(impactEvent.EventId);
            continue;
        }

        if (PerformHitCheck(impactEvent, world) != HitResult.Hit) { ... continue; }

        float baseValue = eventEntity.HasComponent<ImpactValueComponent>()
            ? eventEntity.GetComponent<ImpactValueComponent>().BaseValue : 0f;

        impactEvent.IsCritical = CheckCritical(impactEvent, world);
        if (impactEvent.IsCritical) baseValue *= GetCriticalMultiplier(impactEvent, world);

        float finalValue = CalculateFinalValue(impactEvent, baseValue, world);
        ApplyImpactToTarget(impactEvent, finalValue, world);

        impactEvent.IsProcessed = true;
        eventEntity.SetComponent(impactEvent);
        _processedEvents.Add(impactEvent.EventId);
        world.DestroyEntity(eventEntity);
    }
    CleanupProcessedEvents();
}
```

## 5.4.2.3 最终数值（修饰器 + 简化防御）

```csharp
private float CalculateFinalValue(ImpactEventComponent impactEvent, float baseValue, EcsWorld world)
{
    float finalValue = baseValue;
    if (impactEvent.Target.HasComponent<ImpactModifierComponent>())
    {
        var sorted = impactEvent.Target.GetComponent<ImpactModifierComponent>().Modifiers
            .OrderByDescending(m => m.Priority).ToList();
        foreach (var m in sorted)
            finalValue = m.IsPercentage ? finalValue * (1 + m.Value) : finalValue + m.Value;
    }
    if (impactEvent.ImpactType == ImpactType.Physical) { /* * 100/(100+DefenceAD) */ }
    else if (impactEvent.ImpactType == ImpactType.Magical) { /* * 100/(100+DefenceAP) */ }
    return finalValue;
}
```

`ImpactType.True` 跳过防御段。

## 5.4.2.4 写回目标、黑板与受击表现（`ApplyImpactToTarget` 核心）

```csharp
private void ApplyImpactToTarget(ImpactEventComponent impactEvent, float finalValue, EcsWorld world)
{
    var targetEntity = impactEvent.Target;
    var targetData = targetEntity.GetComponent<EntityDataComponent>();

    switch (impactEvent.TargetAttribute)
    {
        case TargetAttribute.Hp:
            ApplyHpChange(targetData, finalValue, impactEvent.OperationType);
            break;
        case TargetAttribute.Mp:
            ApplyMpChange(targetData, finalValue, impactEvent.OperationType);
            break;
        // AtkAD / DefenceAD / MoveSpeed / … → ApplyCoreAttributeChange 或 ApplyBonusAttributeChange
    }

    if (impactEvent.TargetAttribute == TargetAttribute.Hp
        && impactEvent.OperationType == ImpactOperationType.Subtract && finalValue > 0f
        && impactEvent.Source.IsValid() && targetEntity.HasComponent<CombatBoardLiteComponent>())
    {
        var board = targetEntity.GetComponent<CombatBoardLiteComponent>();
        board.LastDamageFromEntityId = impactEvent.Source.Id;
        targetEntity.SetComponent(board);
    }

    if (impactEvent.TargetAttribute == TargetAttribute.Hp
        && impactEvent.OperationType == ImpactOperationType.Subtract && finalValue > 0f)
        HitFxRelay.RaiseHpDamaged(impactEvent.Target, finalValue);

    targetEntity.SetComponent(targetData);
}
```
