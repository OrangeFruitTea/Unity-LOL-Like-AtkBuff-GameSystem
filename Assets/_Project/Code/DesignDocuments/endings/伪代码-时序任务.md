# 4.5.2 时序任务调度与派发 — 关键代码与说明

Basement 用 **`ITimingTask`** 统一任务形态，**`TimingTaskManager`** 负责登记与排序，**`TimingTaskScheduler`** 按节拍递减计时并 **`Execute`**。**`MatchTimeService`** 门控：对局未进行或已暂停时 **`deltaTime` 视为 0**，与对局时间语义一致。Unity 场景用 **`TaskDispatcher`**；若启用 ECS 泵送，则由 **`BasementUnityPump.PumpTimingTasks`**（或 `PumpUpdate` bundle）替代 MonoBehaviour 里的 `Update` 推进。

---

## 4.5.2.1 任务契约

```csharp
public interface ITimingTask
{
    string TaskId { get; }
    TimingTaskState State { get; }
    TimingTaskPriority Priority { get; }
    float DelayTime { get; }
    void Execute();
    void Cancel();
}

public enum TimingTaskState { Ready, Running, Completed }
public enum TimingTaskPriority { Low = 0, Normal = 1, High = 2 }
```

**`TimingTaskBase`**：`Execute` 将状态置 `Running`，调用子类 `ExecuteInternal`，成功则 `Completed` 并回调；`Cancel` 将未完成者标记为 `Completed`。

## 4.5.2.2 管理器（创建与排序）

```csharp
public TimeTriggeredTask CreateTimeTriggeredTask(Action action, float delayTime,
    TimingTaskPriority priority = TimingTaskPriority.Normal)
{
    var task = new TimeTriggeredTask(action, delayTime, priority);
    RegisterTask(task);
    return task;
}

private void RegisterTask(ITimingTask task)
{
    lock (_lock)
    {
        _tasks[task.TaskId] = task;
        _taskQueue.Add(task);
        _taskQueue.Sort((a, b) => {
            int c = b.Priority.CompareTo(a.Priority);
            return c != 0 ? c : a.DelayTime.CompareTo(b.DelayTime);
        });
    }
}
```

另有 `CreatePeriodicTask`、`CreateConditionalTask`、`CreateScheduledTask`；`ClearAllTasks` / `CancelTask` 用于释放。

## 4.5.2.3 调度器（节拍 + MatchTime 门控）

```csharp
public void Update()
{
    if (UnityEngine.Time.time - _lastUpdateTime < _updateInterval) return;

    float deltaTime = UnityEngine.Time.time - _lastUpdateTime;
    _lastUpdateTime = UnityEngine.Time.time;

    var match = MatchTimeService.Instance;
    if (!match.IsMatchActive || match.IsMatchPaused)
        deltaTime = 0f;

    ProcessTasks(deltaTime);
}

private void ProcessTasks(float deltaTime)
{
    lock (_lock)
    {
        foreach (var task in TimingTaskManager.Instance.GetAllTasks())
        {
            if (task.State == TimingTaskState.Ready)
            {
                if (!_taskTimers.ContainsKey(task)) _taskTimers[task] = task.DelayTime;
                _taskTimers[task] -= deltaTime;
                if (_taskTimers[task] <= 0 && !_activeTasks.Contains(task))
                {
                    _activeTasks.Add(task);
                    task.Execute();
                    if (task is PeriodicTask p && p.State == TimingTaskState.Ready)
                        _taskTimers[task] = p.Interval;
                    else if (task is ConditionalTask c && c.State == TimingTaskState.Ready)
                        _taskTimers[task] = c.CheckInterval;
                    else
                        _taskTimers.Remove(task);
                }
            }
            else if (task.State == TimingTaskState.Completed)
                _taskTimers.Remove(task);
        }
        _activeTasks.RemoveAll(t => t.State == TimingTaskState.Completed);
    }
}
```

## 4.5.2.4 Unity 集成与集中泵送

```csharp
// TaskDispatcher.cs
private void Awake()
{
    TimingTaskManager.Instance.Initialize();
    TimingTaskScheduler.Instance.Initialize();
    MatchTimeService.Instance.BeginMatch();
}

private void Update()
{
    if (BasementLoopRouting.IsEcsPumpActive) return;
    MatchTimeService.Instance.TickUpdate();
    TimingTaskScheduler.Instance.Update();
}
```

```csharp
// BasementUnityPump.cs
public static void PumpTimingTasks() => TimingTaskScheduler.Instance.Update();

public static void PumpUpdate()
{
    PumpMatchTimeUpdate();
    PumpTimingTasks();
    PumpGameEvents();
}
```

启用 **`BasementLoopRouting.IsEcsPumpActive`** 时，`TaskDispatcher.Update` 早退，由 **`BasementPumpEcsSystem`** 等调用 `BasementUnityPump.PumpUpdate()` 统一推进。

## 4.5.2.5 扩展：`BatchTaskProcessor`、`TaskPool<T>`

- **批量**：`BatchTaskProcessor` 将多任务攒到 `_batchSize` 或超过 `_batchInterval` 后 `ProcessBatch` 内逐个 `Execute`。
- **池化**：`TaskPool<T>`（`new()` 约束）`Get` / `Return` 复用任务实例，可与 `RegisterTask` 组合，降低短生命周期任务分配。

编辑器下 **`TaskDebugWindow`** 可展示 `TimingTaskManager` 统计并清空任务（`#if UNITY_EDITOR`）。
