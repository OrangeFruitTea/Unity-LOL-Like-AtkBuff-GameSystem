# 5.5.1 技能执行管线逻辑 — 关键代码与说明

本节说明技能从「门面入口」到「ECS 管线系统」再到「Buff 施加」的链路，代码与配置分布在 `Assets/_Project/Code/Scripts/Gameplay/Skill/`（`Context`、`Config`、`Runtime`、`Ecs`、`Buff`、`Conditions`、`Targeting`）。**表驱动**：`SkillDefinition.Steps` 描述每一步 Buff 施加；`PipelineScheduleBuilder` 把 `Immediate` / `AfterDelay` 折成按施法起点对齐的时间批次；`OnCondition` 每帧由 `SkillConditionRegistry` 求值；`OnEvent` 在当前实现中仍为占位（见下文 `ProcessEventStub`）。

---

## 5.5.1.1 设计意图（概要）

单次施法构造 **`SkillCastContext`**（施法者、主目标、副目标列表、技能等级、`CastStartedUnityTime`）。**`SkillExecutionFacade.TryBeginCast`** 校验目录、上下文、目标需求、冷却，写入 `CastStartedUnityTime`，调用 **`SkillCastPipelineSystem.TryBegin`**，成功后再 **`SkillCooldownTracker.NotifyCast`**。**`SkillCastPipelineSystem`**（`UpdateOrder = 50`）每帧推进条件步、定时批次与事件占位逻辑，满足时经 **`BuffApplyService`** 对解析出的实体施加 Buff。复杂编排留在 JSON/配置与注册表，减少手写分支。

## 5.5.1.4 定时批次折叠（`PipelineScheduleBuilder`）

```csharp
public static List<ExecutionBatch> BuildTimedBatches(SkillDefinition def)
{
    var entries = new List<(float t, int idx)>();
    for (int i = 0; i < def.Steps.Count; i++)
    {
        var s = def.Steps[i];
        switch (s.TriggerKind)
        {
            case BuffApplicationTriggerKind.Immediate:
                entries.Add((0f, i));
                break;
            case BuffApplicationTriggerKind.AfterDelay:
                entries.Add((Mathf.Max(0f, s.DelaySecondsFromCastStart), i));
                break;
        }
    }
    entries.Sort(...);
    // 相同 t（Mathf.Approximately）合并为一个 ExecutionBatch.StepIndices
    ...
}
```

`CollectConditionStepIndices` / `CollectEventStepIndices` 分别收集 `OnCondition` / `OnEvent` 的下标，供会话维护 `PendingConditionSteps`、`PendingEventSteps`。

## 5.5.1.6 管线系统（`SkillCastPipelineSystem`）

会话按施法者 ECS Id 唯一；`TryBegin` 构建 `TimedBatches`、待处理条件/事件步集合，并设置 **`SkillPipelineRuntimeComponent.HasActiveCast`**。

```csharp
public int UpdateOrder => 50;

public void Update()
{
    float now = Time.time;
    foreach (var kv in _sessions)
    {
        var session = kv.Value;
        if (session.Cancelled || !IsContextAlive(session.Context)) { done.Add(kv.Key); continue; }

        ProcessConditionSteps(session, now);
        ProcessTimedBatches(session, now);
        ProcessEventStub(session);

        if (IsSessionComplete(session)) done.Add(kv.Key);
    }
    foreach (var id in done) EndSession(id);
}

private void ProcessTimedBatches(SkillCastSession session, float now)
{
    float t0 = session.Context.CastStartedUnityTime;
    while (session.NextBatchIndex < session.TimedBatches.Count)
    {
        var batch = session.TimedBatches[session.NextBatchIndex];
        if (now < t0 + batch.FireTimeFromCastStart) break;
        foreach (int stepIndex in batch.StepIndices)
            ExecuteStep(session, stepIndex);
        session.NextBatchIndex++;
    }
}

private void ProcessEventStub(SkillCastSession session)
{
    if (session.PendingEventSteps.Count == 0 || session.LoggedEventStub) return;
    session.LoggedEventStub = true;
    Debug.LogWarning("[SkillCastPipeline] ... OnEvent 步骤，当前版本未实现事件订阅 ...");
    session.PendingEventSteps.Clear();
}
```

**实现说明**：若配置含 `OnEvent`，当前版本不会订阅外部事件总线，仅告警并清空待定事件步，使会话仍可结束。设计上的完整语义应为：事件 id 与步骤 `EventId` 匹配时再 `ExecuteStep`。

`ExecuteStep` 内：`DefaultTargetResolver` 解析目标 → `SkillParameterResolver.ResolveBuffLevel` → `BuffApplyService.TryApplyStep`。具体 Buff 工厂内可再创建 Impact 等玩法效果，管线类本身不直接分支伤害公式。
